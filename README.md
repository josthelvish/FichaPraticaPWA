# Programação Web Avançada
## Mestrado em Engenharia Informática e Tecnologia Web

Ficha prática para treino de manuseamento de conteúdos em repositórios Github.

> **Nota Prévia:** A execução desta atividade pressupõe a leitura prévia da documentação de apoio indicada no Moodle.

---

### Preparação do Repositório

Na sua conta na plataforma GitHub crie um repositório público, de nome `FichaPraticaPWA`.

> **NOTA:** As tarefas indicadas de seguida devem ser realizadas na sequência pedida de forma a ser possível consultar o seu rastreio na plataforma GitHub.

---

### Tarefas

1. À parte deste repositório, no seu PC, crie um ficheiro de texto, de nome `"Perguntas.txt"` e coloque dentro o seguinte conteúdo:
   1. O que são operações de "Commit", "Push" e "Pop" efetuadas num repositório?
   2. Quais são as vantagens de usar Branchs num repositório git?
   3. Nos Merges de conteúdos resultantes de um "Pop" podem resultar em conflitos. Em que consistem e como podem ser resolvidos esses conflitos?
   4. "Clone" e "Fork" são formas diferentes de replicar um repositório Git. Quais as diferencas entre eles?

2. Submeta este ficheiro, consoante está, no repositório anteriormente criado.

3. Agora, no seu PC, edite o ficheiro anterior colocando a resposta a apenas uma das perguntas (qualquer uma delas).

4. Atualize o repositório remoto executando os comandos git adequados.

5. Repita os dois passos anteriores (3 e 4) mais três vezes, respondendo, em cada uma das vezes, a mais uma pergunta das ainda não respondidas.
   * *No final deste processo, o repositório remoto deve conter o ficheiro de texto com as 4 perguntas e as 4 respostas.*

6. Novamente no seu PC, crie um novo ficheiro de nome `"Perguntas.html"` com o mesmo conteúdo do anterior (todas as perguntas e respostas) mas formatado em HTML.
   * O documento deve conter elementos HTML capazes de representar:
     * Parágrafos
     * Listas numeradas
     * Listas não numeradas
     * Formatações de texto: **bold**, *itálico* e <u>sublinhado</u> (pode recorrer a CSS para aplicação dos estilos).

7. Depois de concluído o ficheiro, adicione-o ao repositório remoto.
